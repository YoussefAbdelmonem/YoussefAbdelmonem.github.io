# Youssef Abdelmonem — Flutter showcase videos

Static site for GitHub Pages. Open `index.html` locally, or publish:

1. Create a public repo named `<your-github-username>.github.io` (or any name).
2. Push this folder; in **Settings → Pages** choose branch `main`, folder `/ (root)`.
3. Site: `https://<username>.github.io/` (or `/<repo-name>/`).

Add a new video: put the MP4 in `videos/` (keep each file < 100 MB), a poster JPG in
`posters/`, and append one object to `PROJECTS` in `index.html`.
